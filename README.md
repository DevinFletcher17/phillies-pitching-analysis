# Phillies Pitching Analysis (2025)

This project analyzes Philadelphia Phillies pitchers using baseball pitching metrics in Microsoft Excel.

## Metrics Used

* ERA
* WHIP
* HR/9

## Charts Created

* ERA vs WHIP comparison
* HR/9 by pitcher

## Goals

The purpose of this project was to compare Phillies pitchers across run prevention, baserunner prevention, and home run suppression.

## Tools Used

* Microsoft Excel
* FanGraphs data
* Baseball analytics concepts

## Key Takeaways

* Pitchers with lower WHIP values generally produced lower ERAs.
* Certain pitchers were more effective at limiting home runs than others.
* The project helped visualize pitching performance using basic baseball analytics metrics.
